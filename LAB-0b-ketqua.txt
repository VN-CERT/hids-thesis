================================================================
2. CAI wrk2 VA HAI SCRIPT TAI CO DINH (CHUA CHAY) — DAT
================================================================
Cai wrk2 (neu chua co — may nay chua co):
apt-get install -y build-essential libssl-dev zlib1g-dev git
git clone https://github.com/giltene/wrk2 /opt/wrk2
cd /opt/wrk2 && make
cp /opt/wrk2/wrk /usr/local/bin/wrk2
-> wrk 4.0.0 [epoll] (/usr/local/bin/wrk2)

Hai script tai co dinh, CHUA chay (chi bash -n va goi khong tham so de in cach dung):
1. scripts/lab0-load-postgres.sh <TPS> <thoi_luong_giay> [thu_muc_log]
   Co dinh: pgbench -R <TPS> -c 16 -j 4 -T <giay> -l --log-prefix=<thu_muc_log>/pglog
   (pgbench chay tu host toi 127.0.0.1:15432; thu_muc_log mac dinh /srv/hids-data/hids-collector/pgbench-logs)
2. scripts/lab0-load-nginx.sh <RPS> <thoi_luong_giay>
   Co dinh: taskset -c 0-3 wrk2 -t4 -c64 -R <RPS> -d<giay>s --latency http://127.0.0.1:18080/file4k.bin

Moi script nhan TPS/RPS va thoi luong lam tham so, tu kiem tra tham so la so nguyen duong.

================================================================
3. VACUUM + CHECKPOINT TRUOC MOI LUOT pgbench — CO TRONG SCRIPT
================================================================
Trong scripts/lab0-load-postgres.sh, truoc lenh pgbench, dung hai lenh rieng qua docker exec, dung thu tu:
docker exec -e PGPASSWORD=... lab0-postgres psql -U postgres -h 127.0.0.1 -v ON_ERROR_STOP=1 -c 'VACUUM;' postgres
docker exec -e PGPASSWORD=... lab0-postgres psql -U postgres -h 127.0.0.1 -v ON_ERROR_STOP=1 -c 'CHECKPOINT;' postgres
