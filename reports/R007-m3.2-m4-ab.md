2. **Mục tiêu**  
   Hoàn thành M3.2 (wl, g3 v3), chuẩn bị và chạy M4 E1/E3/E4; chuẩn bị E2 cho người dùng; gắn tag `m4-ab` (chưa `m4` vì E2 chưa chạy).

   - `bin/rec-export`, `analysis/m4.py`, `scripts/m4.sh`, `bin/m4_e3`; chạy E1, E3, E4; `validation/m4-20261007/`.

4. **Lệnh build, lệnh chạy**  
   ```bash
   make build
   bash scripts/g3.sh m32
   bash scripts/m4.sh calibrate
   bash scripts/m4.sh all          # hoặc e1 / e3 / e4 riêng
   bash scripts/m4.sh e2           # hướng dẫn E2 (người dùng)
   env PYTHONNOUSERSITE=1 PYTHONPATH=/usr/lib/python3/dist-packages \

     --summary validation/m4-20261007/summary.csv E1:0:... ...
   ```

9. **Việc người dùng cần làm tay (E2 — steal)**  
   1. Trên máy đã `bash scripts/m4.sh calibrate` (có `out/m4-loops.txt`).  
   2. Chạy `bash scripts/m4.sh e2` và đọc hướng dẫn in ra.  
   3. Trước mỗi mức Limit MHz trên vCenter: **Edit Settings → CPU → Limit = &lt;X&gt; MHz → OK**, bấm Enter trên máy.  
   4. Mức: Unlimited, 36000, 24000, 12000 MHz; đồng thời `stress-ng --cpu 23` trên CPU 0–19,21–23 và `wl -loops $(awk '/^burn_loops/{print $2}' out/m4-loops.txt) mixed 500` trên CPU 20 với collector `-pid`.  
   5. Cuối cùng đặt lại **Unlimited**.
